# JagtFokus v1 — frosset spec

App-navn: **JagtFokus**
Platform: iPhone, App Store
Stack: Swift + SwiftUI
Min iOS: 18
Sprog: dansk og engelsk. Arter, steder, noter og biologi er dansk i data
Bundle id: `dk.jagtfokus.app`

## Job

Jægeren skal på 5 sekunder se **hvad der er lovligt at jage i dag, her**.

## Med i v1

- Startskærm: kun arter med jagttid på **valgt dato og sted**
- Standard: **i dag** + **her** (GPS). Jægeren kan vælge anden dag og andet sted
- Fane **Alle arter**: hele listen, grupperet, med næste åbningsdato hvis lukket
- Gruppering: klovbærende, rovdyr, øvrige pattedyr, andefugle, gæs, hønsefugle, øvrige fugle. Vadefugle, kragefugle og ringdue ligger i øvrige fugle
- Per art: navn, sæson (fra–til, evt. flere perioder), kort note ved fodnote
- Artsdetalje: biologisk opslag (status i Danmark, yngel, træk). Køn og alder deler arten. Egne kilder i `biologi.json`. Ikke jagtloven, og ikke en del af jagttidsdata
- “Sidst opdateret” + link til bekendtgørelsen på Retsinformation
- Ansvarsfraskrivelse ved første start og under **Om**
- Data: `jagttider.json` bundle i appen + remote GitHub raw
- Offline: bundle er fallback. Remote overskrives kun hvis nyere `version`
- Soltider: solopgang og solnedgang for valgt dato og sted. Beregnes på telefonen (offline). Rækken siger “[Sted], den [dato]”, samme valg som ovenfor. Kun visning
- Fane **Indstillinger**: Udseende System / Lys / Mørk (standard System). **Sammenfold grupper** (standard til) styrer Jagtbart og Alle arter
- Fane **Journal**: notér nedlagt vildt lokalt. Overskrift “Jagtjournal”. Rækken “Nedlagt vildt” åbner årets liste. **Artsliste** er arter nedlagt mindst én gang, én gang hver. Journalen sætter arten på. Sletning i journalen tager den ikke af. Swipe og **Tilføj til journal** gemmer 1 stk. Ingen koordinater. Ingen indberetning
- Journalen ligger i appens mappe, med en lokal reservekopi. Sletning af appen sletter den. Ingen iCloud-synk i denne udgave
- Menuen hedder **Jagtbart**. Status på en art hedder stadig “Jagtbar” / “Ikke jagtbar”
- Infoside **Schweiss-registret**. Ikke en fane. Knappen **Anskudt** på Jagtbart og en række på Om. Anskudt under jagt åbner schweiss.dk. Påkørt hjortevildt ringer 1812. Sekretariatet er hverdagskontakt. Seks dagtimer er tekst, ikke en timer. Ingen telefonliste i appen
- Ingen konto. Ingen tracking.

## Ikke i v1

Solnedgangs-alarm, jagtlog ud over journalen, indberetning til myndighederne, iCloud-synk, hunde-log, opskrifter, etik, telefonliste over schweisshundeførere (venter på tilladelse fra sekretariatet; ingen scrape), Android/Google Play. Kron-/dåvildt-kortbilag.

## Regler for “lovligt her og nu”

- Dato **og** sted afgør listen. Ikke klokkeslæt. Soltider vises, men styrer intet
- Standarddato er i dag (Europe/Copenhagen)
- Standardsted er GPS → mest specifikke sted (ø > område > region > Danmark)
- Uden position: Danmark (generelle tider) + vælger
- En art er åben hvis **en** af de gældende perioder indeholder datoen
- Lokal jagttid slår generel, mere specifikt sted slår region
- Tom periode = ingen jagttid på stedet
- Noter kodes **ikke** som logik. De vises som tekst
- Appen er **ikke** loven. Jægeren skal selv tjekke bekendtgørelse og lokale regler

## Data

Fil: `jagttider.json` (bundle + samme fil på GitHub raw)

```json
{
  "version": 1,
  "updated": "2026-10-10",
  "source_name": "Bekendtgørelse om jagttid (BEK nr. 470 af 24/04/2024)",
  "source_url": "https://www.retsinformation.dk/eli/lta/2024/470",
  "groups": [
    {
      "id": "klovbaerende",
      "title": "Klovbærende",
      "species": [
        {
          "id": "raabuk",
          "name": "Råbuk",
          "periods": [
            { "from": "05-16", "to": "07-15" },
            { "from": "10-01", "to": "01-31" }
          ],
          "note": "Der findes lokale jagttider."
        }
      ]
    }
  ]
}
```

- Datoer er `MM-DD` og gentages hvert år. `to` < `from` betyder årsskifte
- `note` er `null` eller kort dansk tekst
- Flere perioder pr. art er tilladt
- Kilde for v1-data: SGAV jagttabel gældende fra 1. juli 2024 (BEK 470/2024). 2026-revisionen var ikke trådt i kraft 10. okt 2026
- `places[].lat` / `places[].lon`: repræsentativt punkt for soltider. Mangler de, bruges forælderens punkt
- Remote URL: GitHub raw for denne repos `data/jagttider.json`
- Appen tjekker remote ved start hvis der er net. Nyere `version` gemmes lokalt

## Skærme

1. **Jagtbart** — overskrift: “Jagtbart vildt efter tid og sted”. Dato, sted og soltider. Svar-kortet viser antallet. De jagtbare grupper starter sammenfoldet, med en stregtegning. Tom tilstand hvis intet er jagtbart
2. **Journal** — notér nedlagt vildt. Dato og sted kun for denne fane. Årets liste med ret og slet. Artsliste over arter nedlagt mindst én gang. Detaljer i `spec/v2.md`
3. **Alle arter** — generelle jagttider for alle arter. Grupperne starter sammenfoldet, med en stregtegning. Søgning åbner træffene. Ingen dato/sted. Ingen åben/lukket
4. **Indstillinger** — Udseende: System / Lys / Mørk. Sammenfold grupper: til / fra
5. **Om** — fraskrivelse, kilde, `updated`. Nederst sektion **Denne app** med version og dataversion. Række til Schweiss-registret
6. **Schweiss-registret** — infoside, ikke en fane. Anskudt under jagt åbner schweiss.dk. Påkørt hjortevildt ringer 1812. Sekretariatet er hverdagskontakt. Ingen telefonliste

Første start: modal med fraskrivelse. Kræver “Forstået” før listen.

## Fraskrivelse (tekst)

JagtFokus viser generelle jagttider ud fra bekendtgørelsen. Listen kan være ufuldstændig eller forældet. Særlige regler (område, køn, kvote, jagtform) står i noten og i loven. Du er selv ansvarlig for at jage lovligt.
